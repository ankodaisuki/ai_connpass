# V5 合同主催機能 手動確認チェックリスト

## 1. 招待・承諾フロー

### 招待送信
- [x] オーナーでログインし、自分のイベント詳細ページ下部に「合同主催者を招待」フォームが表示される
- [x] フォームに既存ユーザーのメールアドレスを入力して送信すると、招待レコードが作成される
- [x] 招待されたユーザーに「【合同主催のお願い】{イベントタイトル}」の件名でメールが届く
- [x] 返答待ち（Pending）のユーザーに再度招待しようとするとエラーになる
- [x] 承諾済み（Accepted）のユーザーに招待しようとするとエラーになる
- [x] 辞退済み（Declined）のユーザーは再招待できる（Pending に戻りメールが再送される）
- [x] 存在しないメールアドレスで招待しようとするとエラーになる

### 招待への応答（ナビ → 合同主催の招待）
- [x] 招待されたユーザーでログインすると、ヘッダーのユーザーメニューに「合同主催の招待」リンクが表示される
- [x] 保留中の招待が1件以上ある場合、リンクの右にインジゴ色の件数バッジが表示される
- [x] 招待がない場合、バッジは表示されない
- [x] リンクをクリックすると `/my/organizer-invitations` の招待一覧ページに遷移する
- [x] 「承諾する」を押すとステータスが Accepted になり、一覧から消える
- [x] 「辞退する」を押すとステータスが Declined になり、一覧から消える

---

## 2. 公開表示

- [x] 承諾済みの合同主催者の名前がイベント詳細ページの主催者名の横に表示される
- [x] 保留中・辞退済みの招待者の名前は公開ページに表示されない

---

## 3. 権限（オーナー vs 合同主催者 vs 一般ユーザー）

### イベント編集
- [ ] オーナーでログインするとイベント詳細に「編集」ボタンが表示される
- [ ] 合同主催者でログインするとイベント詳細に「編集」ボタンが表示される
- [ ] 一般ユーザーには「編集」ボタンが表示されない

### イベント削除
- [ ] オーナーでログインするとイベント詳細に「削除」ボタン（「この操作は取り消せません」）が表示される
- [ ] 合同主催者でログインすると「削除」ボタンが表示されない

### 出欠管理
- [ ] オーナーは参加者一覧で「参加済み」ボタンを押して出欠を記録できる
- [ ] 合同主催者は参加者一覧で「参加済み」ボタンを押して出欠を記録できる
- [ ] 合同主催者でログインすると参加者の名前が一覧に表示される

### 招待・除名・移譲（オーナーのみ）
- [ ] オーナーには「合同主催者を招待」フォームが表示される
- [ ] 合同主催者には「合同主催者を招待」フォームが表示されない
- [ ] オーナーは合同主催者リストの「除名」ボタンで除名できる
- [ ] 合同主催者には「除名」ボタンが表示されない
- [ ] オーナーには「オーナーを移譲する」フォームが表示される
- [ ] 合同主催者には「オーナーを移譲する」フォームが表示されない

---

## 4. オーナー手動移譲

- [ ] 承諾済み合同主催者を選んで「移譲する」を押すと、その人がオーナーになる
- [ ] 移譲後、旧オーナーが合同主催者として残っている
- [ ] 移譲後、新オーナーの合同主催レコードが削除されている（オーナーは event_organizers に入らない）
- [x] ~~承諾されていない招待者 (Pending) へ移譲しようとするとエラーになる~~ ※移譲フォームには承諾済みユーザーしか表示されないため UI から到達不可。自動テスト（`test_cannot_transfer_to_non_accepted_co_organizer`）でカバー済み

---

## 5. イベント削除（オーナーによる中止）

- [ ] オーナーがイベントを削除すると、申込中・キャンセル待ちの参加者に中止通知メールが届く
- [ ] 削除後、イベントは `/events` の一覧から消える（ソフトデリート）

---

## 6. オーナー退会時の自動処理

### 承諾済み合同主催者がいる場合
- [ ] オーナーを Inactive にすると、最も早く招待された承諾済み合同主催者が新オーナーになる
- [ ] 新オーナーの合同主催レコードが削除される
- [ ] イベントは中止されない（ソフトデリートされない）

### 承諾済み合同主催者がいない場合
- [ ] オーナーを Inactive にすると、イベントがソフトデリートされる
- [ ] 申込中の参加者に中止通知メールが届く
