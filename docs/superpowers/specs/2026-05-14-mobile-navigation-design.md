# モバイルナビゲーション設計書

## 概要

ヘッダーのユーザーメニューがモバイル（`sm:` 未満）で非表示になっている問題を解消する。
ハンバーガーメニューを追加し、モバイルでもプロフィール・申し込み一覧・ログアウトにアクセスできるようにする。

## 変更ファイル

- `resources/views/components/app-layout.blade.php` のみ

## 設計

### デスクトップ（sm以上）
現状のまま：横並びナビ + ユーザー名ドロップダウン（`<details>/<summary>`）

### モバイル（sm未満）
- ハンバーガーアイコンボタン（`☰` に相当するSVG）をヘッダー右端に表示
- `<details>/<summary>` を使ってタップで展開（既存デスクトップドロップダウンと同じ手法）
- 展開時にメニュー項目を縦に並べて表示：
  - プロフィール
  - 申し込み一覧
  - ログアウト
- 未ログイン時はログイン・新規登録リンクをそのまま表示（現状で問題なし）

## スコープ外

- アニメーション（CSS transition は最小限でよい）
- その他ページのコンテンツレイアウト変更（すでに十分レスポンシブ）
